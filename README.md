# Paradise Nursery Shopping Application

## Project Overview

Paradise Nursery is an online plant shopping application where users can explore and purchase a variety of beautiful houseplants.

The application provides an interactive shopping experience that allows users to browse plants by category, view product details, add plants to their shopping cart, and manage cart items.

## Features

- Attractive landing page.
- Browse houseplants across different categories.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- Dynamically calculate the total cart price.
- Responsive navigation between pages.

## Technologies Used

- React.js
- JavaScript
- CSS
- Redux Toolkit
- React Redux
